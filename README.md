# Página personal

Sitio estático de Aymen Hadane El Mouadan, estudiante de DAW.

https://AymenHadaneElMouadan.github.io/pagina-personal/

## Cómo ejecutar

1. Instala las dependencias con `npm install`.
2. Arranca el servidor local con `npm start` y abre http://localhost:8080.
3. Ejecuta la validación HTML y los tests con `npm test`.
